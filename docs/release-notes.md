# Короткие заметки к обновлениям

Перед выпуском добавьте раздел `## MAJOR.MINOR.PATCH` с 3–6 короткими пунктами на русском: исправления, новые возможности и важные изменения поведения. Эти пункты показываются в приложении и в GitHub Release. Полная история остаётся в CHANGELOG.md.

## 0.1.16

- Флаг «Как в Windows» теперь показывает системный язык, независимо от выбранного языка приложения.
- Редактор клипов открывается в правой области приложения, а боковое меню автоматически сворачивается.
- При переходе в настройки или другие разделы монтаж и история отмены сохраняются.
- Пустые проекты и отклонённые автокопии больше не вызывают повторное предложение восстановления.
