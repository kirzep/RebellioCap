# Support

For build and first-run instructions, start with
[Getting started](docs/getting-started.md). Check
[System requirements](docs/system-requirements.md) and
[Troubleshooting](docs/troubleshooting.md) before reporting a failure.

## Ask a question or report a problem

Use [GitHub issues](https://github.com/kirzep/RebellioCap/issues/new/choose) for
reproducible bugs, questions and feature proposals. Search existing issues first
and select the matching template.

For recording or playback problems, include the application version or commit,
Windows version, GPU and driver, selected monitor, audio devices and relevant
recording settings. Explain the steps, what you expected and what happened. If
the issue involves sleep, display changes or a device disconnect, describe the
event and whether capture recovered. A short neutral sample is more useful than
a full personal recording.

For a build failure, include the failing command and the relevant error lines.
Report checks that were not run separately from checks that passed. See
[Testing](docs/testing.md) for the distinction between browser, native and
hardware verification.

## Share diagnostics carefully

Issues and their attachments are public. Review logs and screenshots before
uploading them. Remove usernames, paths, device identifiers, private content and
other unnecessary personal information. Automatic log redaction is limited and
does not make every diagnostic safe to publish.

The desktop application can save a local diagnostic archive after enabling
developer mode by clicking the RebellioCap logo ten times, then using the log
export control in application settings. Exporting saves a ZIP to a folder you
choose; it does not submit a report. See [Privacy and local data](docs/privacy.md)
for archive contents and storage locations.

For suspected vulnerabilities, use the private route in [Security](SECURITY.md).
Do not put exploit details in a public support issue.

Support depends on maintainer availability. This project has no staffed support
desk, response-time commitment or commercial support agreement published here.
