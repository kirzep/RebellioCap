# Community expectations

Keep issues, pull requests, and reviews useful to the people working on this project.

- Discuss behavior, evidence, and proposed changes. Critique code without attacking people.
- Give clear reproduction steps and acknowledge uncertainty or constraints.
- Be considerate of different experience levels, languages, and accessibility needs.
- Do not post harassment, personal information, secrets, private recordings, or exploit details.
- Report vulnerabilities through the [private security channel](SECURITY.md).

Maintainers may moderate disruptive content through GitHub's controls, including removing content or limiting participation. For platform abuse, use GitHub's reporting tools. This development project does not promise dedicated moderation staff or response schedules.

For technical help, use [Support](SUPPORT.md). For changes, use [Contributing](CONTRIBUTING.md).
