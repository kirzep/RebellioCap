# Security

RebellioCap is a local Windows recording application. Reports concerning the C++
engine, Rust desktop host, frontend/native boundary, media and project handling,
or packaged dependencies are welcome.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/kirzep/RebellioCap/security/advisories/new).
Do not publish exploit details, sensitive recordings, credentials or an
unreviewed diagnostic archive in an issue or pull request.

Include:

- The application version or source commit and affected component.
- The impact, required access and conditions under which the issue is reachable.
- Minimal reproduction steps or a small sanitized example, shared privately.
- Any proposed mitigation, if known.

If GitHub's private reporting form is unavailable, check the
[owner's GitHub profile](https://github.com/kirzep) for an available contact
method and request a private channel before sharing sensitive details. No
security email address is published by this repository.

## Versions and response

Identify the exact version you tested and, where practical, whether the issue also
affects the current `main` branch. This repository does not publish a maintained
release-branch matrix or a guaranteed backport policy.

Reports are handled as maintainer availability permits. There is no dedicated,
staffed response service, guaranteed acknowledgement or remediation deadline,
or published bug-bounty program. A private report is the appropriate first step
even when a fix may take time.

Ordinary capture failures, unsupported hardware and feature requests belong in
[Support](SUPPORT.md). See [Privacy and local data](docs/privacy.md) before sharing
logs, media or project files. The presence of this policy is not a claim that the
application or its dependencies have passed an independent security audit.
