## Сохраните то, что уже произошло

RebellioCap хранит недавнюю запись в кольцевом буфере, чтобы удачный момент можно было сохранить **после события**. Записывайте полную сессию и держите мгновенный повтор включённым одновременно. Просматривать и монтировать клипы можно в том же приложении. Записи остаются на вашем компьютере.

| Возможность | Что можно делать |
| --- | --- |
| **Мгновенный повтор** | Сохранять недавний фрагмент горячей клавишей; настраивать длительность и бюджет RAM. |
| **Непрерывная запись** | Писать MP4 или MKV одновременно с Replay. |
| **Аппаратное кодирование** | Захватывать выбранный экран через D3D11 и NVIDIA NVENC H.264. |
| **Управление звуком** | Записывать системный звук и необязательный микрофон. При двух источниках доступны смешанная и отдельные дорожки. |
| **Библиотека клипов** | Смотреть локальные записи, категории и миниатюры; выбирать звуковые дорожки при просмотре. |
| **Редактор** | Обрезать, разделять и переставлять фрагменты; добавлять изображения и текст; менять кадрирование, цвет и громкость. |
| **Экспорт** | Получать H.264/AAC видео с настройками качества и целевого размера; сохранять проекты и шаблоны. |
| **Управление приложением** | Использовать горячие клавиши, трей, автозапуск и настройки уведомлений. |
| **Восстановление** | Возобновлять захват после поддерживаемых сбоев экрана, находить подходящие частичные записи и восстанавливать автокопии монтажа. |

Записывается **выбранный экран целиком**, включая видимые окна и уведомления. Категории игр упорядочивают файлы; внедрение в игру и захват звука отдельного процесса сейчас не реализованы.

## Начало работы

Сейчас репозиторий публикует **исходный код в разработке**. Версия desktop-пакета — `0.1.7`; проверенный бинарный релиз является отдельным этапом. Опубликованные сборки следует искать в [GitHub Releases](https://github.com/kirzep/RebellioCap/releases); условия подготовки описаны в [руководстве по релизам](docs/releases.md).

Для записи нужны **Windows x64**, **NVIDIA с совместимым NVENC H.264** и **WebView2**. Подробности — в [системных требованиях](docs/system-requirements.md). Для сборки также нужны MSVC C++ Build Tools с Windows SDK и CMake/Ninja, Node.js 24 с npm и Rust 1.89+ с MSVC toolchain.

В PowerShell:

```powershell
git clone https://github.com/kirzep/RebellioCap.git
Set-Location RebellioCap

# Проверка окружения и установка зависимостей.
./scripts/verify-prerequisites.ps1
./scripts/bootstrap-vcpkg.ps1
npm ci

# Сборка и подготовка движка.
./scripts/invoke-dev.ps1 -Command @('cmake', '--preset', 'windows-debug')
./scripts/invoke-dev.ps1 -Command @('cmake', '--build', '--preset', 'windows-debug')
./scripts/stage-desktop-engine.ps1 -BuildDirectory build/windows-debug

# Запуск приложения.
npm run desktop:dev
```

Продолжайте после успешного завершения каждой команды. [Пошаговое руководство](docs/getting-started.md) описывает инструменты, первоначальную настройку, первую запись и работу только с интерфейсом.

### Горячие клавиши по умолчанию

| Действие | Комбинация |
| --- | --- |
| Сохранить мгновенный повтор | **Alt + F10** |
| Начать / остановить непрерывную запись | **Ctrl + Shift + R** |

Обе комбинации меняются в настройках. Replay сохраняет только накопленную историю: сразу после запуска или восстановления захвата клип может быть короче выбранной длительности.

## Требования и ограничения

- Захват работает на **Windows x64 с NVIDIA NVENC**. Кодировщики AMD/Intel и другие ОС сейчас не поддерживаются; проверка драйвера и возможностей выбранного режима должна пройти.
- Запись — **SDR BT.709**. Сохранение HDR и tone mapping не реализованы.
- Replay хранит сжатые пакеты в RAM. Место для файлов зависит от битрейта и длительности; [примеры расчёта](docs/system-requirements.md#size-the-recording-workload).
- Нельзя восстановить изображение за время недоступности экрана или байты, которые не успели записаться на диск.
- Максимумы в настройках не означают, что любая видеокарта выдерживает такую нагрузку. Проверки совместимости, производительности и установщика выполняются отдельно.
- Проекты и диагностика могут содержать локальные пути. Проверяйте их перед отправкой; см. [хранение данных](docs/privacy.md).

## Разработчикам

C++20 движок отвечает за захват, звук, кодирование, Replay и контейнеры. Rust/Tauri управляет процессом движка, настройками и файлами. React/TypeScript формирует интерфейс, библиотеку и редактор; встроенные FFmpeg-инструменты готовят предпросмотр и экспорт монтажа.

В [описании архитектуры](docs/architecture.md) разобраны владение GPU-ресурсами, единая шкала времени аудио/видео, лимиты памяти, протокол процессов и восстановление, со ссылками на код и тесты.

```powershell
# C++, Rust, frontend, production bundle и проверка CSP.
./scripts/verify-desktop.ps1

# Браузерные сценарии проверяются отдельно.
npx playwright install chromium
npm run test:e2e -w @rebelliocap/desktop
npm run test:crash-coverage
```

[CI](.github/workflows/desktop-ci.yml) проверяет программные компоненты и браузерные сценарии. Настоящий WebView2, захват на GPU, отключение устройств, длительные сессии и установщик требуют отдельных проверок. Их границы описаны в [руководстве по тестированию](docs/testing.md).
