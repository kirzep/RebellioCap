## Сохраните то, что уже произошло

Играйте с включённым мгновенным повтором и нажмите **Alt + F10**, чтобы сохранить момент после того, как он произошёл. Одновременно можно записывать полную сессию, находить записи в библиотеке и монтировать клипы в RebellioCap. Записи остаются на вашем компьютере.

| Возможность | Что можно делать |
| --- | --- |
| **Мгновенный повтор** | Сохранять недавний фрагмент горячей клавишей. Выбирать длительность и автоматический или ручной лимит RAM. При достижении лимита доступная история может сокращаться. |
| **Запись сессии** | Запускать и останавливать запись в MP4 или MKV одновременно с мгновенным повтором. |
| **Качество записи** | Использовать NVIDIA NVENC H.264 с битрейтом VBR или постоянным QP — CQP. Выбирать исходное разрешение, 1080p или свой размер видео и настраивать FPS. |
| **Приоритет записи** | Повышать приоритет подготовки кадров на GPU. Это может помочь под нагрузкой ценой части FPS игры; результат зависит от оборудования и нагрузки. |
| **Звук и дорожки** | Записывать системный звук и необязательный микрофон. При двух источниках сохранять смешанную и отдельные дорожки, выбирать их при просмотре и монтаже. |
| **Библиотека клипов** | Смотреть миниатюры, искать клипы и папки, группировать записи по папкам, просматривать, переименовывать и открывать их в редакторе. |
| **Редактор** | Обрезать, разделять, дублировать и переставлять связанные видео- и аудиофрагменты. Добавлять изображения и текст, менять кадрирование, прозрачность, цвет и громкость, отменять и повторять действия. |
| **Экспорт для отправки** | Создавать MP4/H.264/AAC. Выбирать умное, тщательное или быстрое сжатие, лимит 20 / 50 / 500 МБ и приоритет плавности, деталей либо сохранения разрешения/FPS. |
| **Проекты и восстановление** | Сохранять `.rebcap` и шаблоны, при необходимости копировать исходники вместе с проектом, восстанавливать локальные автокопии монтажа. Восстанавливать подходящие прерванные записи, если данных достаточно. |
| **Имена и папки** | Собирать шаблоны имён из игры, даты, времени, счётчика, типа записи, разрешения и FPS. Хранить записи по папкам игр или в одной общей папке. |
| **Оверлей и звуки** | Располагать индикаторы записи, Replay и сообщения в конструкторе оверлея. Выбирать сигналы уведомлений, добавлять свой звук и настраивать громкость. |
| **Управление приложением** | Настраивать глобальные горячие клавиши, работать из трея, включать запуск с Windows и устанавливать доступные опубликованные обновления из приложения. |

Захват записывает **весь выбранный экран**, включая другие видимые окна и уведомления. Папки игр упорядочивают записи; захват выбранного окна игры и изоляция звука отдельного приложения сейчас не включены.

## От записи к готовому клипу

### Найдите запись

<img src="docs/screenshots/clips.jpg" width="1120" alt="Библиотека RebellioCap с реальными записями Dead by Daylight и Deadlock, миниатюрами, поиском и группировкой по папкам">

Найдите запись, просмотрите нужный момент, выберите звуковые дорожки и нажмите **Редактировать клип** в меню файла.

### Соберите монтаж

<img src="docs/screenshots/editor.jpg" width="1120" alt="Редактор RebellioCap с настоящей игровой записью и отдельными видео- и аудиодорожками">

Работайте на шкале времени со связанными видео и звуком, привязкой фрагментов и удалением со сдвигом. Меняйте положение и размер прямо в предпросмотре. Добавляйте текст и изображения, выбирайте горизонтальный, вертикальный или квадратный кадр, сохраняйте проект для продолжения работы. Исходники сохраняются.

### Уложитесь в лимит загрузки

<img src="docs/screenshots/export.jpg" width="1120" alt="Окно экспорта RebellioCap со способами сжатия и ограничением размера для Discord">

- **Умное** сначала пробует выбранные разрешение и FPS с целевым качеством. Если файл больше лимита или профиль недоступен, переходит к кодированию с рассчитанным битрейтом.
- **По размеру — тщательное сжатие** сразу использует бюджет битрейта и тщательные настройки кодирования.
- **Быстрое** использует менее требовательный профиль.

Выбирайте приоритет плавности, деталей или **сохранения разрешения и FPS**. Каждая завершённая попытка проверяется по фактическому размеру перед сохранением. Если уложиться не получается, экспорт сообщает об ошибке вместо сохранения слишком большого файла. Пресеты 20 / 50 / 500 МБ задают размер; доступный лимит загрузки проверяйте для своего аккаунта.

Тщательный профиль использует NVENC при наличии поддержки, с резервными вариантами NVENC и Windows Media Foundation. Умное сжатие может занять больше времени. Маленький лимит всё ещё может снизить детализацию; сохранение разрешения и FPS не означает сжатия без потерь.

VBR использует заданный битрейт. CQP задаёт уровень квантования: меньшее число обычно сохраняет больше деталей и увеличивает файл. Размер файлов и расход памяти Replay в CQP зависят от сцены. В настройках есть подсказки с объяснением этих различий.

## Начало работы

1. Скачайте **EXE-установщик для Windows** в [GitHub Releases](https://github.com/kirzep/RebellioCap/releases/latest).
2. Пройдите настройку: выберите экран, источники звука, папку, параметры Replay и горячие клавиши. Запустите встроенную тестовую запись.
3. Играйте с включённым Replay. Нажмите **Alt + F10**, чтобы сохранить недавний момент, или **Ctrl + Shift + R**, чтобы начать/остановить запись сессии.
4. Откройте **Клипы**, выберите запись и перейдите к монтажу или экспорту.

Обе комбинации меняются в настройках. Replay сохраняет только оставшуюся в буфере историю: после запуска, восстановления захвата или достижения лимита памяти клип может быть короче выбранной длительности.

Интерфейс поддерживает **английский и русский**, по умолчанию использует язык Windows и позволяет выбрать язык в боковом меню. README описывает текущее дерево исходников; возможности опубликованного установщика перечислены в его [заметках к релизу](https://github.com/kirzep/RebellioCap/releases).

## Требования и ограничения

- Для записи нужны **Windows x64**, **NVIDIA с совместимым NVENC H.264** и **WebView2**. Кодировщики захвата AMD/Intel и другие ОС не реализованы. Версии ОС/драйвера и проверки совместимости описаны в [системных требованиях](docs/system-requirements.md).
- Захват включает видимое содержимое выбранного экрана. Он не изолирует окно игры или звук одного приложения.
- Видео записывается в **SDR BT.709**; сохранение HDR и tone mapping не реализованы.
- Replay хранит сжатые пакеты в RAM. Его лимит ограничивает удерживаемые сжатые данные, а не всю память приложения и GPU. Размер файлов CQP зависит от сцены.
- Максимумы разрешения/FPS в настройках — границы проверки значений, а не гарантия производительности любой видеокарты. Приоритет записи может влиять на FPS игры.
- Восстановление не возвращает незахваченные кадры или незаписанные байты. Исходники, предпросмотры и экспорт также требуют свободного места на диске.
- Проекты и диагностика могут содержать локальные пути. Перед отправкой прочитайте [описание хранения данных](docs/privacy.md).

## Разработчикам

C++20 движок отвечает за захват, звук, кодирование, Replay и контейнеры. Rust/Tauri управляет процессом движка, настройками и файлами. React/TypeScript формирует интерфейс, библиотеку и редактор; встроенные FFmpeg-инструменты готовят предпросмотр и экспорт монтажа.

Для сборки нужны Windows, MSVC C++ Build Tools с Windows SDK, CMake/Ninja, Node.js 24 с npm и Rust 1.90+ с MSVC toolchain. Установка инструментов и проверки первого запуска описаны в [пошаговом руководстве](docs/getting-started.md).

```powershell
git clone https://github.com/kirzep/RebellioCap.git
Set-Location RebellioCap
./scripts/verify-prerequisites.ps1
./scripts/bootstrap-vcpkg.ps1
npm ci
./scripts/invoke-dev.ps1 -Command @('cmake', '--preset', 'windows-debug')
./scripts/invoke-dev.ps1 -Command @('cmake', '--build', '--preset', 'windows-debug')
./scripts/stage-desktop-engine.ps1 -BuildDirectory build/windows-debug
npm run desktop:dev
```

Продолжайте после успешного завершения каждой команды.

В [описании архитектуры](docs/architecture.md) разобраны владение GPU-ресурсами, единая шкала времени аудио/видео, лимиты памяти, протокол процессов и восстановление, со ссылками на код и тесты.

```powershell
# C++, Rust, frontend, production bundle и проверка CSP.
./scripts/verify-desktop.ps1

# Браузерные сценарии проверяются отдельно.
npx playwright install chromium
npm run test:e2e -w @rebelliocap/desktop
npm run test:crash-coverage
```

[CI](.github/workflows/desktop-ci.yml) проверяет программные компоненты и браузерные сценарии. Настоящий WebView2, захват на GPU, отключение устройств, длительные сессии и установщик требуют отдельных проверок. Их границы описаны в [руководстве по тестированию](docs/testing.md).
