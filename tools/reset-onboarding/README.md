# Сброс первоначальной настройки RebellioCap

1. Закройте RebellioCap обычным способом. Если идёт запись, сначала остановите её.
2. Дважды нажмите **Reset RebellioCap setup.cmd**.
3. Откройте приложение: появится приветственный экран, затем проверка системы и все шаги первоначальной настройки.

Скрипт работает без прав администратора. Настройки текущего пользователя из `%LOCALAPPDATA%\RebellioCap` переносятся в папку `setup-backup-...` рядом с конфигом. Сохранённые видео, драйверы и установленные зависимости остаются на месте. Если приложение открыто, скрипт попросит закрыть его и ничего не изменит.

Текущий мастер проверяет доступность зависимостей и оборудования; отдельного шага установки зависимостей в нём пока нет. Сброс конфигурации не удаляет зависимости Windows.

Проверка без изменений:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\reset-onboarding.ps1 -WhatIf
```

Для восстановления предыдущих настроек закройте приложение и скопируйте `config.json` и `config.last-good.json` из нужной папки `setup-backup-...` обратно в `%LOCALAPPDATA%\RebellioCap`, заменив новые файлы.

Папку с двумя скриптами можно переместить в любое удобное место: путь к проекту им не нужен.
